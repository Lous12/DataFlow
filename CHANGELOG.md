# Changelog

All notable changes to DataFlow will be documented here.

## [0.1.0] - 2026-10-06

### Added
- Desktop GUI built with PySide6
- XLSX, CSV and JSON import
- Drag & drop file input
- Data preview
- File merging
- Empty-row cleanup
- Text trimming
- Duplicate removal
- Sorting
- Multiple filters with AND / OR logic
- Text and numeric filter operators
- Split export by a selected column
- XLSX, CSV and JSON export
- JSON-configured CLI mode
- One-file Windows build script
