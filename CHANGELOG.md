# Changelog

All notable changes to DataFlow will be documented here.

## [0.2.0] - 2026-10-06

### Added
- Local smart file analyzer
- Plain-language analysis summary
- Merge/schema compatibility suggestions
- Empty-row, duplicate and whitespace detection
- Detection of likely article/ID, city, category, price and name columns
- Suggested deduplication, split export and filters
- One-click application of safe cleanup suggestions

## [0.1.0] - 2026-10-06

### Added
- Desktop GUI built with PySide6
- XLSX, CSV and JSON import
- Drag & drop file input
- Data preview
- File merging
- Empty-row cleanup
- Text trimming
- Duplicate removal
- Sorting
- Multiple filters with AND / OR logic
- Text and numeric filter operators
- Split export by a selected column
- XLSX, CSV and JSON export
- JSON-configured CLI mode
- One-file Windows build script
